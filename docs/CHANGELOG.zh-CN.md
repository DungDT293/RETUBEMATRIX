## [1.0.4] - 2026-11-12

### 变更

- **彻底隔离 RETubeMatrix 浏览器配置与运行时数据** - 将浏览器配置存储（`profiles.json`、`deleted_profiles.json` 与 Chromium 用户目录）、运行日志（`run_history.jsonl`）、窗口图标、叠加层状态、AI 评论配置、待发评论及二进制查找统一迁移至 RETubeMatrix 专属数据目录（`%LOCALAPPDATA%\RETubeMatrix\browser_engine` / `RETUBEMATRIX_BROWSER_DATA_DIR`），完全移除从外部 `BrowserMulti` 或旧版 `reupytb` 目录自动读取、回退或迁移的逻辑。
- **纯净安装包打包与作用域受限的 NSIS 安装卸载** - 将 `bundle.resources` 显式限定为 `actions/`、`core/`、`runner.py`、`outlier_hunter.py` 与 `requirements.txt`，防止开发期 `.tmp/`、`logs/` 和 `__pycache__/` 被打入安装包；同时将 NSIS 进程终止限定在 `$INSTDIR` 安装目录内，并在用户勾选删除数据时清理 `%LOCALAPPDATA%\RETubeMatrix\browser_engine`（覆盖升级时完整保留）。

### 修复

- **严格隔离 BKT 测试池配置与功能 2 及仪表盘** - 彻底杜绝版权测试池配置（`group: "Kênh Test BKT"`、`name: "[BKT Test] *"` 及 SQLite 中登记的测试频道 ID）泄露至功能 2（浏览器配置管理）、功能 1（对手频道 1 对 1 绑定）、快速上传弹窗以及仪表盘目标配置指标统计。在分组过滤器中排除测试分组，禁止手动创建保留命名空间的 BKT 配置，并通过 `include_bkt: true` 保证功能 5（BKT 测试频道管理）对自有配置的独占访问。
- **持久保持 Google 登录态与两阶段优雅关闭** - 在 `browsermulti_native.py` 和 `runner.py` 中将所有即时 `taskkill /F` 强制终止重构为两阶段优雅关闭（向各配置顶层窗口发送 Win32 `WM_CLOSE` 并等待最多 8 秒，允许 Chromium 完整将 SQLite WAL 刷新落盘：`Cookies`、`Login Data`、`Network Persistent State`，并写入 `profile.exit_type = Normal`），仅在超时后执行强制终止。
- **保护 Service Worker 与会话缓存防误删** - 在 Rust 后端与 Python 执行器中彻底从缓存清理列表中移除 `Service Worker/CacheStorage`、`Service Worker/ScriptCache` 和 `blob_storage`，在配置处于运行状态时终止清理，并移除普通关闭流程 `finally` 块中的自动清理，永久保全 Google / YouTube Studio 会话登录凭据。
- **原子写入 Preferences 与 WebRTC IP 泄漏防护** - 将 `Preferences` 直接覆写优化为 `.tmp` 临时文件原子替换并保留 `.bak` 备份，避免在会话存在时覆写 `restore_on_startup`，正确透传配置 `locale` 至 `--lang` 参数，强制追加 `--webrtc-ip-handling-policy=disable_non_proxied_udp` 防止 WebRTC 泄露真实本机 IP，并在明文 HTTP 代理转发中注入 `Connection: close` 消除跨域连接复用问题。
- **防止已删除配置复活与空占位目录生成** - 在 `profile_store.py` 磁盘自动恢复阶段严格校验 `deleted_profiles.json` 墓碑与有效 Chromium 目录结构，取消只读 `load_profiles()` 时的快照重写，禁止在浏览器首次启动前创建空目录，并在 `add_profile`、`update_profile`、`restore_deleted_profile` 及 BKT 测试频道自动命名（`[BKT Test]`）中统一执行大小写与空白规范化重名校验。
- **修复仪表盘当日统计准确性与缓存路径解析** - 更新 `get_multibrowser_stats` 与 `clean_multibrowser_profile_cache_native`，按 UTC 日期过滤当日成功/失败与运行次数，从 `user_data_root/logs/run_history.jsonl` 计算真实会话与时长，在所有配置与 BKT 生命周期变更时刷新 `STATS_CACHE`，由 UUID `profile_id` 精确解析 `profile_dir`，并在 `runner.py` 中合并批量停用和分组写入操作。

## [1.0.3] - 2026-11-12

### 新增

- **彻底隔离 BKT 版权测试池与目标发布频道环境** - 将版权测试频道（功能 5）与目标主频道浏览器环境（功能 2）完全解耦。新增或编辑测试频道时，系统自动生成并接管属于独立“Kênh Test BKT”分组的专属 Chromium 实例，绝不关联或误启动主获利频道的浏览器环境。
- **Top 5 长视频单轨串行自动 Reup 流水线 (1-by-1 FIFO)** - 针对监控对手频道实现严格的逐个串行全自动流水线（下载 1 个 -> Reup Lv.1 深度去重 -> 借用测试池 Unlisted 槽位检测 Content ID -> 绿标安全后直发目标主频道 -> 自动清理本地原始/去重/缩略图文件以释放磁盘 -> 自动推进下一个视频）。
- **FFmpeg 预检扫描 (`preflight.rs`) 与多语言 Shadow DOM Studio 核心 (`studio_dom.py`)** - 新增编码前水印/字幕区域预检以及跨语言、穿透 Shadow DOM 的 YouTube Studio 状态检测与安全点击基础库。
- **升级统一本地环回代理桥接与完整 HTTP/2 多路复用** - 支持通过本地后台代理桥接转发带认证的 HTTP 和 SOCKS5 代理，消除 CDP 身份验证死锁并恢复 Google 与 YouTube 服务的 HTTP/2 多路复用。

### 变更

- **规范化目标主频道术语与高配硬件动态资源释放** - 在频道卡片与设置面板中明确“目标主频道 (功能 2)”标识并移除混淆下拉项；针对内存大于 4GB 的计算机解除 256MB JS 堆限制与进程数上限（保留低配 VPS 保护）。

### 修复

- **修复填写标题和简介后 YouTube Studio 上传流程卡死 (`0x0` Shadow DOM)** - 适配外层尺寸为 `0x0` 的宿主元素（`ytcp-uploads-dialog`、`ytcp-video-share-dialog`）、`<slot>` 分发节点以及 Shadow DOM `#scrollable-content` 滚动，稳定完成受众选择、向导翻页、保存发布、链接提取及后续弹窗关闭。
- **杜绝 Shorts 混入长视频队列及新建测试频道误绑环境** - 修复 `polling.rs` 强制设为 `all` 的缺陷并增加 `> 60s` 与 `/shorts/` 过滤，同时确保新建测试频道始终绑定独立环境。
- **修复代理停滞与 Linux CI/CD 打包路径** - 解决本地代理禁用 HTTP/2 导致的卡顿并规范化 AppImage/Flatpak 构建脚本。

## [1.0.1] - 2026-11-11

### 新增

- **多格式智能 Proxy 识别与双协议验证** - 自动识别国内常见 4 段式 Proxy 格式（`IP:Port:User:Pass`，如 Cloudmini 等），无缝转译为标准浏览器代理 URL，并智能支持 HTTPS 与 SOCKS5 端口双协议验证。在配置文件列表中安全脱敏遮蔽代理密码。
- **Reup 流水线实时渲染进度条** - 在 Reup 界面下实时流式呈现编码百分比、渲染速度倍率、当前 FPS 及预估剩余时间 (ETA)。
- **低配硬件智能 FFmpeg 线程限流保护** - 针对 4 核及以下云服务器（如 3 vCPU Windows Server），自动限制使用线程数 (threads = 2)，保留核心维护系统运行，杜绝云服务商 CPU 降频与系统卡死。
- **BKT Studio 一键唤醒与 Google 登录失效诊断提醒** - 为版权测试配置文件提供一键直达 YouTube Studio 快捷按钮，并在后台静默测试遇到 Google 登录失效时即时弹出红框警示与快速登录通道。
- **配置文件列表新增一键打开 YouTube Studio** - 在浏览器环境列表的操作列中新增直达按钮，方便快速完成 Google 登录与频道验证。
- **Auto-Pilot 头部卡片嵌入实时渲染进度条** - 在一键全自动流水线运行第一阶段时，即时显示渲染百分比、编码速率与倒计时。

### 修复

- **BKT 版权验证保真度规范 (BKT Verification Honesty)** - 明确区分技术故障与真实侵权，防止网络异常或未登录状态被错误归类为 `red_matched`（侵权检出）。
- **全站选择框代理密码脱敏遮蔽** - 对所有测试频道与主发布频道的下拉选择项启用统一脱敏函数 `maskProxy`，杜绝凭证泄露。
- **无声视频 FFmpeg 崩溃保护** - 增加音频流探测逻辑 (`probe_has_audio_stream`)，对无音轨视频自动传入 `-an`，避免音频重采样滤镜报错崩溃。
- **进程泄露与 31 分钟超时阻塞修复** - 启用子进程 `kill_on_drop(true)`，并在获取确切测试结果后立即主动关闭检查器，无需等待 1860 秒超时。
- **CI/CD 打包环境目录预备** - 在 GitHub Actions 打包流水线中增加静态资源目录创建，修复云端构建 Tauri 安装包失败的问题。
- **JWT Base64URL 静默刷新与 Token 会话持久化** - 修复 JWT 解密补齐符号导致自动续签失败的问题，确保后台长时间运行任务不会意外掉线。
- **租户公司名称转译与 PostgreSQL UUID 格式兼容** - 增加自动将公司代码/名称转译为底层 UUID 逻辑，彻底杜绝 REST 请求引发的 `22P02` 错误。
- **清理 SaaS Master Hub 重复渲染的升级弹窗** - 消除企业套餐升级对话框的多余渲染副本。
